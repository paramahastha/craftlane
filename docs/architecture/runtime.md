# Runtime observation boundary

Craftlane keeps provider adapters private. Each adapter detects local support, merges one marked project-scoped integration artifact, and projects provider input into the allowlisted `ObservationEnvelope`. The authenticated loopback callback and canonical reducer own validation, deduplication, durable ordering, snapshots, and browser delivery.

Observation is read-only. The bridge never returns provider decisions and never forwards prompts, messages, commands, transcript paths, tool arguments/results, environment values, or secrets. Missing provider capabilities are reported as unavailable; the dashboard does not infer parity.
